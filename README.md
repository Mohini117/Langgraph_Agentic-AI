# 🚀 LangGraph Agentic AI

A structured implementation of **Agentic AI systems using LangGraph**, built as a progressive hands-on learning repository.  
This project demonstrates how to build stateful AI workflows using graph-based orchestration.

---

## 📌 Overview

This repository explores:

- Building AI agents with structured workflows
- Implementing state management in AI systems
- Designing graph-based execution pipelines
- Creating iterative reasoning loops
- Developing multi-step agent coordination

The project is organized in a **day-wise progression format (DAY1, DAY2, etc.)**, where each folder builds upon the previous concepts.

---

## 🧠 What is Agentic AI?

Agentic AI systems are:

- **Stateful** (maintain memory across steps)
- **Iterative** (reason, evaluate, improve)
- **Graph-structured** (nodes + edges execution)
- **Tool-integrated** (can call external functions/APIs)

Unlike simple prompt-response models, agentic systems execute multi-step reasoning workflows.

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Mohini117/Langgraph_Agentic-AI.git
cd Langgraph_Agentic-AI
```

### 2️⃣ Create Virtual Environment (Recommended)

```bash

source venv/bin/activate   # Mac/Linux

```

```bash

```
